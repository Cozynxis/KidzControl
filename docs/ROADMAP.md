# Roadmap
## V2 web
Authentication, family onboarding, multiple child profiles, realtime rule sync, requests, schedules, category filters, activity timeline, notifications, settings, developer tools and responsive Kids Mode.

## V2.1
Supabase-first state adapter, invite codes, email recovery, per-day schedules, temporary exceptions, category editor, richer charts, audit log and notification center.

## V3
Installable PWA, offline shell, push notifications and tablet-focused Kids Mode.

## Future native agent
Optional Windows/Android companion for supported device-level enforcement. It should be visible to the device user, authenticated, revocable and never designed as hidden surveillance.
